\subsubsection*{Brightness and Hollowness}
\addcontentsline{toc}{subsubsection}{Brightness and Hollowness}
\begin{description}
  \item[\texttt{pure}:] Only the fundamental is nonzero, so there is no higher-frequency content. It sounds the least bright of the four, with a very smooth but dull overall sound.
  \item[\texttt{odd\_1k}:] Only the odd harmonics are nonzero, with amplitudes decaying as $1/k$. It sounds very bright, and also the hollowest of the four.

  \item[\texttt{all\_1k}:] All harmonics are present, with amplitudes decaying as $1/k$. It sounds bright, but with a fuller sound compared to \texttt{odd\_1k}.
  \item[\texttt{all\_1k2}:] All harmonics are present, but the amplitudes decay as $1/k^2$, so the higher harmonics die out much sooner. It sounds mellower than the $1/k$ tones.
\end{description}

The brightest tones are the ones whose harmonic amplitudes decay as $1/k$ (\texttt{odd\_1k} and \texttt{all\_1k}), because they contain more high-frequency content. The pure tone has no high-frequency content, and in \texttt{all\_1k2} the $1/k^2$ decay makes the higher harmonics fall off much faster. Hollowness is more of a result of the harmonic pattern: the hollowest tone, \texttt{odd\_1k}, has only odd harmonics. Generally, tones built from only odd harmonics (such as square waves) sound hollower than other tones.

\subsubsection*{Tone Shape}
\addcontentsline{toc}{subsubsection}{Tone Shape}
\begin{description}
  \item[\texttt{pure}:] The \texttt{pure} tone looks like an ordinary sine wave, since it is built from the fundamental alone with no additional frequency content.
  \item[\texttt{odd\_1k}:] The \texttt{odd\_1k} tone looks like a square wave. This matches the Fourier series of a square wave, whose coefficients are zero for even harmonics and proportional to $1/k$ for odd harmonics.
  \item[\texttt{all\_1k}:] The \texttt{all\_1k} tone looks like a sawtooth wave, consistent with the Fourier series of a sawtooth, whose coefficients are proportional to $1/k$ for all harmonics $k \geq 1$.
  \item[\texttt{all\_1k2}:] The \texttt{all\_1k2} waveform appears to lie between a sawtooth and a pure sine wave, just as the magnitude plot of its coefficients lies between those of the sawtooth tone (\texttt{all\_1k}) and the pure tone (\texttt{pure}).
\end{description}

The pattern of coefficients determines the waveform's shape in two ways. First, which harmonics are present sets the overall profile: odd harmonics alone produce a square wave, while all harmonics with the same $1/k$ decay produce a sawtooth. Second, how fast the coefficients decay determines how sharp the features of the waveform are, with faster-decaying coefficients leading to a smoother, more sine-like waveform.

    # returns t/t_a during the rise (t < t_a), exp decay afterwards

\subsubsection*{Comparison}
\addcontentsline{toc}{subsubsection}{Comparison}
Although the \texttt{all\_1k} tone is multiplied by two different envelopes, one with a gradual rise and one without, both resulting tones sound the same, and no click is audible. This is because the original tone is built entirely from unshifted sine waves, so it starts at zero amplitude for both envelopes. For a tone that starts at a nonzero amplitude, such as one built from cosines, a click would be audible, since the sudden jump in amplitude would introduce high-frequency content.

freqs = {"C4":261.63, "D4":293.66, "E4":329.63, "F4":349.23, "G4":392.00, "A4":440.00}

\subsubsection*{Comparison with Labs 2 and 3 for Fourier-series Output}
\addcontentsline{toc}{subsubsection}{Comparison with Labs 2 and 3 for Fourier-series Output}

In Lab 3, a cosine input to the two-stage RC cascade produced a cosine output whose steady-state magnitude and phase were
\[
M(\omega) = \frac{G}{\sqrt{1+(\omega\tau_1)^2}\,\sqrt{1+(\omega\tau_2)^2}},
\qquad
\phi(\omega) = -\tan^{-1}(\omega\tau_1) - \tan^{-1}(\omega\tau_2).
\]
The magnitude and phase of the frequency response derived here are
\[
|H(j\omega)| = \frac{G}{\sqrt{1+(\omega\tau_1)^2}\,\sqrt{1+(\omega\tau_2)^2}},
\qquad
\angle H(j\omega) = -\tan^{-1}(\omega\tau_1) - \tan^{-1}(\omega\tau_2),
\]
which are identical.

The two results agree because they are two different ways of computing the same LTI system's output. In Lab 3, the output was found directly by convolving the cosine input with the impulse response, and the steady-state magnitude and phase were read off once the transient had decayed. Here, the eigenfunction property is used instead: an input $e^{j\omega t}$ produces the output $H(j\omega)\,e^{j\omega t}$. Since a cosine is a sum of two complex exponentials, its steady-state output is a cosine scaled by $|H(j\omega)|$ and shifted by $\angle H(j\omega)$. Because both methods describe the same system, they must give the same magnitude and phase.

\begin{lstlisting}
A = 1.0
f0 = 10.0
w0 = 2*np.pi*f0
T0 = 1.0/f0

def square_wave(t, T):
    sq = np.zeros_like(t)
    for i in range(len(t)):
        rem = t[i] % T
        if rem < T/2:
            sq[i] = A
        else: 
            sq[i] = -A
    return sq

tau1, tau2, G = 10e-3, 4.7e-3, 5.7
def H(f):
    jw = 1j*2*np.pi*f
    return G / ((1 + jw*tau1) * (1 + jw*tau2))

def y_fs(t, f0, N=99):
    w0 = 2*np.pi*f0
    y = np.zeros_like(t)
    for k in range(1, 2*N, 2):
        Hk = H(k*f0)
        y = y + (4*A/(np.pi*k)) * np.abs(Hk) * np.sin(k*w0*t + np.angle(Hk))
    return y

def y_conv(f0, dt=5e-5):
    nper = 6
    t = np.arange(0, nper/f0, dt)
    x = np.sign(np.sin(2*np.pi*f0*t)); x[x == 0] = 1
    th = np.arange(0, 12*tau1, dt)
    h = G/(tau1 - tau2) * (np.exp(-th/tau1) - np.exp(-th/tau2))
    yc = np.convolve(x, h)[:len(t)] * dt
    return t, yc

# f0 = 10 Hz
tc, yc = y_conv(10.0)

fig2, ax2 = plt.subplots(figsize=(10, 5))
ax2.plot(tc, yc, label='Convolution')
ax2.plot(tc, y_fs(tc, 10.0), '--', label='Fourier series')
ax2.set_title('Filtered Square Wave, f0 = 10 Hz')
ax2.set_xlabel('t (s)')
ax2.set_ylabel('amplitude')
ax2.legend()
fig2.tight_layout()

#  f0 plots
for f in [2, 10, 40]:
    tt = np.arange(0, 2/f, 1/f/10000)
    fig, ax = plt.subplots(figsize=(10, 5))
    ax.plot(tt, square_wave(tt, 1/f), label='Input square wave')
    ax.plot(tt, y_fs(tt, f), label='Filtered output')
    ax.set_title(f'f0 = {f} Hz')
    ax.set_xlabel('t (s)')
    ax.set_ylabel('amplitude')
    ax.legend()
    fig.tight_layout()

# values
for f in [2, 10, 40]:
    print(f'f0 = {f} Hz:', [round(abs(H(k*f)), 3) for k in [1, 3, 5, 7, 9]])

plt.show()
\end{lstlisting}

\subsubsection*{Mathematical Explanation of Behavior}
\addcontentsline{toc}{subsubsection}{Mathematical Explanation of Behavior}

Each input harmonic has amplitude $4A/(\pi k)$, so its output amplitude is
\[
B_k=\frac{4A}{\pi k}|H(jk\omega_0)|,
\qquad k=1,3,5,\ldots.
\]
The gains for the first three odd harmonics are shown below.

\begin{table}[H]
    \centering
    \begin{tabular}{cccc}
        \toprule
        $f_0$ (Hz) & $|H(j\omega_0)|$ & $|H(j3\omega_0)|$ & $|H(j5\omega_0)|$ \\
        \midrule
        2  & 5.646 & 5.252 & 4.629 \\
        10 & 4.629 & 1.999 & 0.969 \\
        40 & 1.362 & 0.204 & 0.075 \\
        \bottomrule
    \end{tabular}
    \caption{Filter gains at the first three odd harmonics.}
    \label{tab:harmonic_gains}
\end{table}

At \SI{2}{\hertz}, the first few harmonics have similar gains, so the output keeps much of its square wave shape with rounded transitions. The flat portions approach $\pm5.7$ because the circuit's DC gain is $G=5.7$.

At \SI{10}{\hertz}, the third and fifth harmonics receive much less gain than the fundamental. This reduces the sharp transitions and makes the output smoother.

At \SI{40}{\hertz}, the third and fifth harmonic gains are small compared with the fundamental gain, so the output is nearly sinusoidal. The phase shifts from $H(jk\omega_0)$ also cause the output to lag the input.

The steady-state output contains only the odd harmonics already present in the input: $f_0,3f_0,5f_0,\ldots$. The LTI circuit changes their amplitudes and phases without creating new frequencies.

\subsubsection*{Integrals}
\addcontentsline{toc}{subsubsection}{Integrals}

Define $\theta=\omega_0t$ and $\theta_c=\arcsin(L/A)$. Splitting the coefficient integral where clipping begins gives
\[
C_k=\frac{4}{\pi}
\left[
A\int_0^{\theta_c}\sin\theta\sin(k\theta)\,d\theta
+
L\int_{\theta_c}^{\pi/2}\sin(k\theta)\,d\theta
\right],
\qquad k \text{ odd}.
\]

The calculations below evaluate both integrals for $k=1$ and for odd $k\geq3$.

\subsubsection*{\(C_1\) and \(C_k\) Values}
\addcontentsline{toc}{subsubsection}{\texorpdfstring{\(C_1\)}{C1} and \texorpdfstring{\(C_k\)}{Ck} Values}

For $C_1$,
\[
\boxed{
C_1=\frac{2A}{\pi}
\left[\theta_c+\sin\theta_c\cos\theta_c\right].
}
\]

For the remaining odd harmonics,
\[
\begin{aligned}
C_k &=
\frac{2A}{\pi}
\left[
\frac{\sin((k-1)\theta_c)}{k-1}
-
\frac{\sin((k+1)\theta_c)}{k+1}
\right] \\
&\quad+\frac{4L}{\pi k}\cos(k\theta_c),
\qquad k=3,5,7,\ldots.
\end{aligned}
\]

The signal is odd, so its DC and cosine coefficients are zero. Its half-wave symmetry makes the even sine harmonics zero.

\subsection*{Task 3.3}
\addcontentsline{toc}{subsection}{Task 3.3}

\subsubsection*{Clip\_Ck}
\addcontentsline{toc}{subsubsection}{Clip\_Ck}

The function uses the expressions derived in Task 3.2, with $k=1$ handled separately.

\begin{lstlisting}[style=python]
def clip_Ck(k, A, L):
    theta_c = np.arcsin(L/A) #get the angle

    if k % 2 == 0: #even k
        return 0.0

    if k == 1: #when k = 1
        return (2*A/np.pi) * (
            theta_c + np.sin(theta_c)*np.cos(theta_c)
        )

    first = np.sin((k-1)*theta_c)/(k-1) #first part
    second = np.sin((k+1)*theta_c)/(k+1) #second part

    #when k is odd and not 1
    return (2*A/np.pi)*(first - second) + \
           (4*L/(np.pi*k))*np.cos(k*theta_c)
\end{lstlisting}

\subsubsection*{Code}
\addcontentsline{toc}{subsubsection}{Code}
\begin{lstlisting}
import numpy as np
from scipy.io import wavfile

fs = 44100
f0 = 220.0
A = 1.0
L = 0.5*A
t = np.arange(0, 2.0, 1.0/fs)

def envelope(t, t_a=0.01, tau_d=0.15):
    #rise then decay
    return np.where(t < t_a, t/t_a, np.exp(-(t-t_a)/tau_d))

#make the sine
tone_clean = A*np.sin(2*np.pi*f0*t)

#clip the sine
tone_clipped = np.clip(tone_clean, -L, L)

#normalize and add the envelope
tone_clean_envelope = tone_clean / np.max(np.abs(tone_clean)) * envelope(t, tau_d=0.5)
tone_clipped_envelope = tone_clipped / np.max(np.abs(tone_clipped)) * envelope(t, tau_d=0.5)

#save the clean tone
clean_i16 = np.int16(tone_clean_envelope * 32767)
wavfile.write("clean.wav", round(fs), clean_i16)

#save the clipped tone
clipped_i16 = np.int16(tone_clipped_envelope * 32767)
wavfile.write("clipped.wav", round(fs), clipped_i16)   
\end{lstlisting}

\subsubsection*{LTI-vs-nonlinear Contrast}
\addcontentsline{toc}{subsubsection}{LTI-vs-nonlinear Contrast}

The LTI circuit in Part 2 changes the amplitude and phase of each harmonic already present in the input, but it cannot create new frequencies. By the eigenfunction property, each complex exponential $e^{jk\omega_0 t}$ in the input appears in the output at the same frequency, scaled by $H(jk\omega_0)$, and by linearity the output to a sum of harmonics is the sum of their individual outputs. As a result, every input frequency maps only to itself. The clipping in Part 3, by contrast, is nonlinear, so there is no guarantee that each input frequency maps only to itself, and even a single sinusoid can come out as a non-sinusoidal waveform. This is why clipping produces the new odd harmonics seen in Task 3.3, which an LTI system could never generate.

\section*{Conclusion}
\addcontentsline{toc}{section}{Conclusion}

This lab used Fourier series coefficients to study the shape, sound, and processing of periodic signals. In Part 1, tones were synthesized from chosen harmonic amplitudes, showing how the coefficients set both timbre and waveform shape. In Part 2, a square wave was approximated with a finite number of harmonics and filtered through the RC circuit, where the Fourier series and convolution outputs agreed once the startup transient decayed. In Part 3, clipping a sine wave produced new odd harmonics, and as the clipping became more severe, the normalized coefficients $C_k/L$ approached those of a unit-amplitude square wave.

\begin{itemize}
    \item Tones with the same fundamental frequency can sound different because their harmonic amplitudes are different. The tones with stronger higher harmonics sounded brighter.
    \item Multiplying a tone by an envelope makes it sound more like a real instrument note. An abrupt onset can cause an audible click, because a sudden jump in amplitude introduces high-frequency content. Since our tones were built from sine harmonics, they already started at zero amplitude, so no click was heard. A tone built from cosines would start at its peak, and that jump would make the click audible.
    \item Adding more terms to the square wave approximation narrowed the ringing near each jump, while the peak overshoot stayed close to \SI{18}{\percent} of $A$.
    \item The RC filter changed the amplitudes and phases of the existing harmonics. Symmetric clipping added higher odd harmonics to the sine wave, which made the tone sound buzzier.
\end{itemize}
